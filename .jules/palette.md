## 2026-02-05 - [Template Inheritance & Accessibility]
**Learning:** Centralizing global styles like `:focus-visible` in a base template while using Jinja2 inheritance reduces code duplication and ensures accessibility is consistently applied across both minimalist landing pages and content-heavy subpages.
**Action:** Always check for redundant code between index and base templates and use inheritance to enforce consistent UX patterns like focus indicators and copy polish.
